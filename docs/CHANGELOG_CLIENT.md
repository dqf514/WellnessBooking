## 本次更新（2026-11-28）：会员卡状态统一口径，权限矩阵可勾选，排课支持批量操作

对应《MODIFY1129》的 12 条修改，前 10 条为功能改动，第 11、12 条为评估与排查。

### 持卡状态筛选改成多选，叫法也统一了

- 「有有效卡」原来多了一个「有」，现在统一写作**「有效卡」**；同一组选项对齐为：无会员卡、未激活、已过期、已用完。
- 这一项从单选改为**多选**：可以同时勾「有效卡」和「已过期」，勾选之间是「或」的关系，命中任意一项的会员都会列出来。
- 原来红框里的「未开卡」改为**「无会员卡」**，「开卡日期待定」改为**「未激活」**（卡已开出、首次签到时自动激活）。

### 名单里一眼看出卡的状态和颜色

- 持卡状态一栏直接显示**已过期**、**已用完**等具体状态，不再只有「有卡 / 无卡」。
- 颜色全系统统一：**正常使用中＝绿色、未激活＝黄色、已过期与已用完＝红色、无会员卡＝灰色**。
- 会员档案里同样上色：未激活黄色，使用中显示「正常」且为绿色，已过期与已用完红色。

### 会员档案的卡按类型分组

- 卡不再平铺一串，按**团课卡、私教卡、体测评估（单列）、年卡·组合套餐、工作坊**分组展示。
- 每组内**有效卡排最前**，后面才是未激活、已过期、已用完等失效卡。
- 新增**「全部卡 / 有效卡 / 失效卡」**三个筛选按钮，一键只看还能用的卡或已失效的卡。

### 翻页、删除与备注

- 会员名单右下角翻页条新增**「首页」「末页」**按钮与**页码输入框**，输入页码回车即跳转，不必再一页一页地点。
- 会员档案里每张卡外侧多余的红色**「删除」按钮已取消**（与卡内已有的「销卡」重复、容易误触），作废一张卡统一走「销卡」。
- 会员档案**备注放大两号**，并设最高显示高度，内容超出后框内出现滚动条，不会把整页撑开。

### 教练管理开放给前台，权限矩阵改为可勾选

- **「教练管理」现在对前台开放**：前台可以维护教练、教室与课程库资料，不再只有管理员能做。
- 原来的角色权限表是只读的，现在可以**直接勾选**：后台「系统设置 → 角色权限」里逐个角色逐项打勾或取消，保存后立即生效；管理员一列固定全选，避免把管理员权限关掉。

### 排课支持批量删除与按日期复制

- 排课列表每行前加**复选框**，勾选后底部浮出批量操作条。
- **批量删除**有两种方式：取消课程（保留记录）、移入回收站（可恢复）；已产生预约的课程不允许进回收站，会逐条说明原因。
- **按日期复制课表**：选来源日期与目标日期即可把当天课按原时段、教练、教室复制过去，可只复制某类课程，也可一次给多组日期。

### Outlook 会议室预定能否导入

- **可以导入**。系统已有「教室预定导入 Outlook 日历」功能，上传 .ics 即可，按 .ics 里的地点与系统教室名匹配，并标记来源为 Outlook。
- 因此 **2027 年底之前的会议室预定**只要能导出 .ics，就可以批量导进新系统。
- 注意教室名必须与系统完全一致，不一致的记录会被跳过（导之前可先把 .ics 里的地点改成与系统一致）；导入按事件唯一标识去重，重复导入不会产生重复预定。

### 公司网络下页面长时间「加载中」的排查

- **慢的不是后端**：本轮已把两个明显的后端瓶颈去掉——会员名单等列表原先整表读出再在 Python 里过滤，现在改到 SQL 层过滤，单次查询从约 0.22 秒降到 0.09～0.15 秒。
- 剩余等待主要来自**公司网络的带宽与延迟**：前端静态资源含约 742 KB 与 375 KB 的 JS 及 733 KB 的 CSS，带宽受限或需走代理时首次打开会等较久，之后有缓存会明显变快。
- 建议让公司网络对本站域名**不走代理**，并开启 gzip 与静态资源缓存。

## 本次更新（2026-11-28）：签到留在弹窗里，教练可以自己排顺序

### 前台签到不再跳回外层页面

- 团课「预约名单」里点「签到消课」后，<b>弹窗留在原地</b>，顶部提示「某某：签到消课成功」，名单就地刷新，可以接着给下一位会员签到。
- 「取消签到」「取消」「爽约」同样在弹窗内完成，成不成功都有提示条说明原因。
- 扣不动课时，报错会直接列出<b>会员现有卡与被拒原因</b>（类别不适用 / 次数不足 / 已到期 / 停卡中），不用再猜是哪里不对。

### 健康评估也能消课

- 健康评估同样是一种课，<b>现在可以正常消课</b>：卡产品类别选成团课或私教都认，团课名健康评估优先用评估卡。
- 未填有效期起止日期的卡不再被误判为已过期；撤销签到时原样退回原来那张卡。

### 教练可以检索，也可以自己排顺序

- 排课时选择教练可以<b>边输入边筛</b>，输入姓名、擅长课程或手机号都能过滤。
- 教练档案新增「排序编号」：<b>编号小的排前面</b>，主打教练放最上面；表头可点击排序，也能一键「前移 / 后移」。
- 同样的检索与排序补到了课程库、卡课产品、预约名单、会员通知与财务流水等列表；卡课产品按团课、私教评估、年卡分组显示。

### 界面细节

- 教室总览里教室的<b>中英文名上下两行</b>同时显示，只填中文就只显示中文、只填英文就只显示英文。
- 「预约教室」里用不到的「Outlook 会议」选项已删除（Outlook 日历导入功能保留）。
- 会员档案的「团课预约记录」「私教预约记录」「消费记录」统一改成与「体测 / Assessment」一样的<b>白色卡片</b>。
- 购卡界面的卡课产品可自己排序，也能输入名称<b>直接检索</b>。

## 本次更新（2026-11-28）：员工手机号撞号不再报错

### 绑定手机号时不再报 500

- 以前把某个员工账号移入回收站后，再把这个手机号绑定给另一个账号会直接报 500 错误；现在改成<b>中文提示</b>：「该手机号已被 系统管理员（admin）绑定」，并把提示显示在<b>编辑弹窗里</b>，不用关掉弹窗才知道没保存成功。
- 如果这个号码只被<b>回收站里已删除的账号</b>占用，系统会<b>自动把号码转给新账号</b>，操作照常完成；被删除账号的其余资料保留，随时可以还原。
- 手机号格式写错时仍然提示「手机号格式不正确」。

### 换一台机器重装依赖也能正常打包

- 之前在没装额外类型包的机器上执行 `npm run build` 会失败，现在补齐了依赖声明，重装依赖后直接打包即可通过。

## 本次更新（2026-11-26）：中英文名称分家，一键清除全部数据

### 资源与商品的名称不再中英文混在一起

- 勤鸟导出的课种、教室、教练与卡产品名称常常把中文和英文写在一起（例如「瑜伽拉伸与声音共振 Yogic Stretch & Sound Resonance」「健康评估Assessment」）。现在导入时会<b>自动拆开</b>：中文写进名称栏、英文写进英文名栏，列表、详情与导出都不再混排。
- 名字本来就带英文缩写的（例如「太极FIT」「国庆疗愈季 活力zumba舞蹈」「呼吸Pro®️伸展复原」）<b>原样保留</b>在中文名里，不会被误拆。
- 随附一份<b>适配好的导出 ZIP</b>：每张表增加「中文名 / 英文名」两列，导入时优先采用；原始导出目录保持不动。
- 已经导入过的旧库，<b>再导入一次同样的数据</b>，混排的名称会被顺手改写好，排期与签到的匹配不受影响，各表仍然是「导入 0」。

### 后台新增「一键清除全部数据」

- 「系统设置 → 数据清除」可一键清空全部业务数据，方便重新导入一套干净的历史资料。
- <b>清除码只通过短信发送</b>到系统内置的手机号 18602113774，界面和接口都不会显示清除码；10 分钟内有效、只能用一次，60 秒内不能重复发送。
- 填入清除码并原样输入确认口令「清除全部数据」后，会员、会员卡、课种、教练、教室、排课、预约、流水与全部历史记录一次性清空，上传的会员照片等附件也一并清掉。
- <b>保留</b>：场馆名称、Logo、备份计划、短信通道、API 密钥等与商业无关的系统设置，以及当前管理员账号（密码重置为 Tpc@2026，需重新登录）。
- 清除后系统<b>不再自动写入演示数据</b>，重启后台也不会冒出示例会员；整个过程写入操作日志留痕。

## 本次更新（2026-11-26）：会员名单分页显示，长姓名不再挤乱表格

### 会员上千也能秒开，名单按页翻看

- 导入几千位会员后，<b>会员管理不再一屏拉到底</b>：名单改为<b>分页显示</b>，默认每页 50 条，底部可以直接翻到下一页。
- 底部还可以切换<b>每页 20 / 50 / 100 条</b>；换了筛选条件（搜索、卡种、排序）会<b>自动回到第 1 页</b>，底部同时显示<b>共有多少位会员</b>。
- 加载速度从原来的一次性拉取几千条记录，变成只取当前一页，<b>打开明显更快</b>。

### 长姓名、长卡名怎么显示都不乱

- 表格<b>按固定列宽排版</b>：<b>姓名再长也只在自己的格子里换行</b>，不会把后面的手机号、金额挤到断行。
- <b>手机号、购卡价格与到期日始终保持一行</b>，方便一眼扫读和核对。
- 一位会员有<b>多张有效会员卡</b>时，改为<b>一张卡一个小标签</b>依次排列、自动换行，超过 4 张折叠成「+N」，鼠标悬停可以看到全部卡名。

### 会员档案侧边可以直接搜人

- 打开会员档案后，右侧<b>会员列表新增搜索框</b>，输入姓名或手机号就能直接切换到要找的会员，不用在几千人里翻。
- 预约、财务与会员通知页改用<b>精简版会员名单</b>，打开速度更快。

## 本次更新（2026-11-26）：名单只留真客户、评估单列、通知群发与 Outlook 日历导入

### 会员名单和导出只统计真正买过卡的客户

- 之前的<b>会员列表、报表导出和「当月新进会员」</b>把没买卡的客人也算进去了，现在<b>只显示买过会员卡的客户</b>。
- 导出前可以<b>按卡种多选</b>：团课、私教、年卡 / 组合套餐；也可以按「当月新进会员」「当月未续会会员」导出。
- 会员列表默认<b>按会员卡种类自动排序</b>（年卡 → 团课月卡 → 十次卡 → 六次卡 → 周卡 → 私教次卡），列表底部会显示<b>每种卡各有多少人</b>。
- 名称统一：「套餐」改称「<b>年卡/组合套餐</b>」，「新建会员」改称「<b>新建客户</b>」。

### 健康评估单独成页，不再扣错卡

- 后台侧边栏新增「<b>评估预约</b>」，健康评估从私教里独立出来，签到时只扣<b>评估权益</b>，不会再误扣年度身心套餐里的私教次数。
- 私教 / 评估签到名单里<b>点会员名字就能直接打开会员档案</b>，不用再回会员列表里翻。

### 会员档案与配色细节

- 会员档案头部<b>照片与姓名放在左侧并整体放大</b>（中文名在上、英文名在下），<b>详细信息在右侧分两行排列</b>（手机号、性别、出生日期、获客来源、会籍归属、微信号、紧急联系），字号比普通表格更大；窗口变窄时自动改成照片姓名在上、信息整行铺开。
- 常用颜色<b>补全</b>，去掉点不开的「更多颜色」，改为提示<b>点击左边的色块</b>直接选择。

### 后台导航栏可以折叠成图标栏

- 左侧导航栏右上角新增一个<b>折叠按钮</b>：点一下整条菜单收到最左边，只剩一排图标，右侧的内容区随之变宽；再点一次展开回完整菜单。
- 折叠状态下把鼠标移到「预约与签到」「排课中心」「资源与商品」等<b>分组图标</b>上，子菜单会在右侧以浮层展开，文字照常显示。
- 每个图标都有悬停提示，鼠标停上去就能看到对应的页面名称；<b>折叠状态会被记住</b>，下次打开后台仍是上一次的样式。
- 窗口本来就比较窄（侧边栏本来就只显示图标）时，折叠按钮会自动隐藏。

### 购卡与升卡可以自己选入账方式

- 购卡、升卡界面现在都能像<b>手动入账</b>一样选择「<b>入流水 / 入营收 / 营收每日均摊</b>」，并显示当前系统的默认口径。
- 默认口径在「<b>系统设置 → 财务口径</b>」里修改，界面上也有说明。

### 后台新增「会员通知」

- 可以给<b>全部会员、已购卡客户或指定会员</b>群发短信，并<b>指定发送日期</b>，到点由系统自动发送，也可以立即发送或取消。
- 内置「<b>预约系统切换</b>」模板，11 月 28 日发一条通知、告知 12 月 1 日起启用新预约系统，填一下内容即可。
- 同一页面可以一键下载「<b>会员手机端操作指南 PDF</b>」（建桌面快捷方式、登录、预约团课、取消预约、看课程介绍、老师资料、自己的卡和预约），转发给会员即可。

### 导入 Outlook 会议室日历

- 教室页新增「<b>导入 Outlook 日历</b>」：把 Outlook 会议室日历导出成 <b>.ics</b> 文件后上传，系统自动生成教室占用。
- 可以按日程地点<b>自动匹配教室</b>，也可以手动指定；<b>重复导入不会重复占用</b>，与已有课程冲突的日程会跳过，不会覆盖现有排课。

### 勤鸟历史数据一键导入本系统

- 后台「<b>系统设置 → 历史数据导入</b>」新增导入面板：把旧系统（勤鸟运动 SaaS）导出的目录压成 <b>ZIP</b> 上传，<b>会员、会员卡、排课、签到、消课与业绩流水一次性带进来</b>，不用再手工誊抄。
- <b>先勾「先演练（只统计不写库）」</b>上传一次，页面会逐表给出读取 / 导入 / 跳过数量和需要人工确认的提示；确认无误后取消勾选再传一次，即为正式导入。
- <b>重复导入是安全的</b>：每条数据带外部 ID，重复上传只会跳过已有记录，不会产生重复会员、卡、预约或流水，已有档案也不会被覆盖；同一批数据再导一次，各表「导入」全是 0、「跳过」等于读取数，可以放心重试。
- 营收按本系统口径重算：<b>团课卡购卡时确认、年卡与组合套餐按有效天数每日均摊、私教与健康评估在实际消课时才确认</b>，与现在的报表口径一致。

## 二、双向二维码签到

新增两种到店签到方式，减少前台逐一核对姓名和会员排队等待：

### 会员出示二维码

1. 会员进入“我的 → 到店签到”，选择“出示我的码”。
2. 前台在预约页面点击“扫码签到”，扫描会员二维码。
3. 系统自动匹配可签到课程并完成签到、消课。
4. 如果同一时段有多节预约，前台可先选择课程，确认前不会扣课。

### 会员扫描课程二维码

1. 前台打开课程“预约名单 → 课程签到码”。
2. 将会员课程码展示在手机或前台屏幕上。
3. 会员进入“我的 → 到店签到”，选择“扫课程码”。
4. 系统只签到该会员本人已经预约的对应课程。

### 使用规则

- 支持团课、私教、评估和工作坊。
- 开课前 30 分钟至课程结束可签到。
- 动态二维码会自动刷新，降低二维码被转发或复用的风险。
- 重复扫码只提示已签到，**不会重复扣课**。
- 误签到可撤销，原会员卡次数或体验券会同步返还。
- 摄像头不可用时，可粘贴完整签到码，或由前台在预约名单中手动签到。

## 三、购卡申请与取消

- 卡课产品支持次卡、周期卡、私教卡和组合套餐。
- 组合套餐可按课程类型分别管理权益，签到和撤销都会对应正确的权益项目。
- 支持会员卡延期、批量延期、冻结、恢复和剩余次数校正。
- 支持升卡、转卡和家庭共享，共享会员可按规则使用同一张卡。
- 可发放免费体验券，并用于真实预约和签到消课。
- 支持会员到期提醒、日常跟进提醒和生日前 7 天提醒。
- 合同、评估资料和其他附件支持上传、下载、修改名称或分类、删除及恢复。
- 重要卡权益调整需要填写原因，便于后续核对。

## 六、财务与经营报表

- 到店售卡时，会员卡和购买流水同时生成，避免开卡与入账不一致。
- 支持电子码核销、手工入账、退款和流水导出。
- 手工入账可用于记录系统外完成、但需要统一入账的收入。
- 退款会保留原始记录；全额退款可关联销卡，已产生的上课历史不会被删除。
- 财务页面分别展示现金实收、购买及升卡入账、退款支出和待核销订单。
- 经营报表提供预约人次、实际上课、课程取消、教练课时、教室使用率等数据。
- 现金实收和确认营收分开列示，便于理解收款与实际课程履约之间的差异。
- 年卡、私教和团课按各自业务规则统计营收，报表更贴近实际经营情况。
- 可导出会员、预约和财务数据，用于对账和内部分析。

## 七、后台与手机端体验

- 手机端继续使用汉堡菜单，保留完整导航。
- 修复后台切换页面时内容区域左右抖动的问题。
- 修复后台页面刷新或直接打开链接时出现“页面不存在”的问题。
- 修复后台品牌标题颜色不清晰的问题。

## 八、品牌、通知与权限

- 管理员可上传和替换系统 Logo 及网站图标，也可恢复默认图片。
- 短信通知支持预约成功、预约取消和课前提醒，可按需要分别开启。
- 支持短信余额查询、测试短信和发送记录查询。
- 真实短信启用前可先测试，确认签名、模板、手机号和余额无误后再正式使用。
- 员工账号支持管理员、前台、财务、教练和只读角色。
- 可新增员工、调整角色、重置密码和停用账号。
- 系统对接访问凭证可在后台统一管理，包括使用范围、有效期、启停和使用记录。

## 九、数据维护与误删恢复

- 支持下载会员导入模板并批量导入会员。
- 重复手机号可选择跳过或更新已有资料。
- 支持会员、预约和财务流水导出。
- 支持立即备份、自动备份、下载备份和按备份恢复数据。
- 恢复数据前会自动保留当前数据副本。
- 可编辑资料、合同和附件均补齐新增、查看、修改和删除能力。
- 删除的数据会进入回收站，管理员可查找并恢复。
- 回收站数据保留 **180 天**，只有管理员且到期后才能彻底删除。
- 合同和附件在回收站期间保留，彻底删除时才清理文件。
- 对仍有有效预约、未来排课或上课历史的数据，系统会阻止直接删除，避免影响正常经营。

> **备份提醒：** 数据库备份不包含合同、照片、Logo 等独立上传文件。完整备份时，还需要同步备份上传文件目录。
