# 音昱 Wellness 系统更新说明（客户版）

**更新周期：** 2026-11-09 至 2026-11-18
**适用对象：** 场馆管理者、前台、财务、教练及会员
**更新范围：** 会员预约、购卡、扫码签到、排课、教室总览导航、会员档案优化、会员管理、财务、报表、教练账号关联、员工自助、后台导航与角色权限

本次更新围绕场馆日常经营流程，完善了从课程安排、会员购卡、预约到课、签到消课，到财务入账、经营分析和数据备份的完整流程，同时优化了手机端和后台操作体验。

## 本次更新（2026-11-18）：会员档案头部重排

### 名字看得清

- 会员档案抽屉顶部的头像改为深色底白字，与浅色背景形成明显反差，姓氏首字一眼就能看清。
- 头像由竖长的圆角块改为紧凑的小方块，头部整体高度明显下降。

### 中文名大字、英文名小字，同一行

- 姓名移动到头像右侧，中文名用大号字体，英文名用小号字体并排在同一行，两个名字一眼就能对上。
- 英文名过长时自动省略，不会把版式挤乱。

### 个人信息一行铺满

- 手机号、性别、出生日期、获客来源、会籍归属、微信号、紧急联系合并为一行，横向铺满整个抽屉宽度，不再竖着堆在中间。
- 手机端自动改为两列排布，文字过长自动省略，不会出现横向溢出。

### 备注直接显示在头部

- 会员备注以浅色条的形式显示在个人信息下方，打开档案即可看到，不必再翻记录。
- 同步修复了会员端“个人信息”面板与后台档案抽屉样式串扰导致的显示错乱问题。

### 更紧凑，留出更多可用高度

- 头部上下留白收紧，把会员卡、体验券和下方记录表的可用高度让了出来，翻页与查看都更省事。

## 本次更新（2026-11-18）：教室总览导航与列宽优化

### 表格顶部新增左右滚动按键

- 教室多的时候，横向滚动条落在很长的表格底部，值班的人常常要拖到页面最下面才找得到。现在在日期栏和表格之间加了一条操作带，最左、最右两个按键就能把教室视图向左、向右平移。
- 到达最左或最右时，对应的按键会自动置灰，不会出现"点了没反应"的情况。
- 操作带中间是教室色块条，会跟着表格的滚动位置一起移动，可以直接当滚动条用。

### 颜色体现当天有没有排课

- 每间教室对应一枚色块，按当天安排着色：绿色表示有课程排课，橙色表示只有内部使用或企业活动占用，灰色表示当天空闲。
- 点击色块即可横向定位到该教室；鼠标悬停可以看教室名称、楼层与当天的课时数。
- 左右按键在该方向存在有排课的教室时会高亮提示，方便一眼找到当天有课的教室。

### 教室列变窄，一屏能看更多教室

- 教室列的最小宽度由 150px 压缩到 104px，同样的屏幕宽度下可见教室明显增多，房间名称与容量信息依然完整。
- 左侧时间轴不再跟着横向滚动，查看右侧教室时时间刻度始终留在原位。
- 手机端保持原有的分页卡片式排版，顶部操作带只在宽屏出现。

## 本次更新（2026-11-18）：会员自助资料与获客来源规范化

### 会员端新增“个人信息”

- 会员端“我的”新增“个人信息”标签页，集中展示会员编号、入会时间与当前绑定手机号（手机号做掩码显示）。
- 姓名与生日可由会员自行维护：姓名不能为空，生日不能填未来日期，保存后立即生效并同步到后台会员档案。
- 会员不再需要为改一个名字或生日专门联系前台。

### 更换手机号需要双重验证

- 修改绑定手机号时，需要先获取“原手机号验证码”，再获取“新手机号验证码”，两段验证码都通过后才会真正换号。
- 新手机号如果已被其他会员使用，系统会直接拦截并说明原因，避免出现一号两人。
- 换号后旧号码不能再作为验证码接收方，会员本人旧号仍保留在操作日志中（手机号掩码），便于核查。

### 后台“获客来源”改为下拉选择

- 会员档案里的“获客来源”由自由输入改为下拉选择，内置行业常用渠道：到店路过、朋友推荐、教练推荐、老会员复购、线上注册、小红书、抖音、微信公众号/视频号、微信朋友圈/社群、搜索引擎、大众点评、美团团购、异业合作、企业团建、活动/体验课、其他。
- 选择“其他”时可再补充一句说明（如“小区业主群”），方便后续复盘各渠道的转化。
- 历史会员档案中已有的自定义来源不会被自动改写，仍可在下拉框中看到并继续使用。

## 本次更新（2026-11-18）：后台导航、课程库与角色权限

### 左侧菜单按角色显示

- 左侧菜单按登录账号的角色显示：财务看不到排课，教练看不到财务与系统设置，只读账号只保留与查看相关的入口。
- 菜单重新分组为“预约与签到 / 排课与场地 / 资源与商品 / 财务与报表”，并按日常使用频率排序，找页面更快。
- 看不到的菜单，其对应页面也打不开（直接输入网址同样会被拦下），避免误入后操作到不该动的数据。
- 同一页面里当前角色不适用的操作按钮会直接隐藏，不再出现“点了才提示无权操作”。

### 侧边栏底部更清爽

- 左下角原来的“English / 操作指南 / 会员预约端”三项，收起为横向排列的三个精简图标按钮（语言、操作指南、会员预约端），鼠标悬停即有说明。
- 手机端的侧边栏同样适用，底部不再堆叠长文字。

### 系统设置新增“更新日志”页

- “系统设置”新增“更新日志”标签页，直接标明当前系统版本号、接口版本与更新批次数量。
- 更新内容以日期为分界逐条列出，每个批次给出日期、版本号与一句话概述，再按主题分组说明主要内容。
- 页面可直接跳转本次更新的完整图文说明（含全部界面截图），也可打印为 PDF 发给同事。

### 课程库独立成页

- 课程库从“排课”页面里的弹窗提升为“资源与商品 → 课程库”独立页面，位置与其他资源一致。
- 支持按课程类别、启停状态与名称搜索筛选，可切换卡片视图与表格视图。
- 新增课程、编辑资料、启用停用、上传与移除课程图片、移入回收站，增删改查与其他资源页面完全一致。
- 排课页面右上角保留“课程库”入口，可一键跳转到新页面。

### 角色权限体系

- 后台“账号权限”页新增权限矩阵表，可直接看到五种角色分别能做哪些操作，无需对照文档。
- 教练可以书写私教与跟进记录，但不能修改会员资料、卡权益与财务数据。
- 财务可以维护卡课产品、办理收款与核销、查看报表与导出，但不能改排课和会员档案。
- 前台负责预约、签到、会员与会员卡维护、收款与核销；课程、教室、教练等基础资料与系统设置仍由管理员维护。
- 移入回收站按数据种类校验，回收站的查看、恢复与彻底删除仍只有管理员可以操作。

### 权限收紧后的日常影响

- 前台仍可核销会员线上提交的购卡电子码，但不再显示全部收支流水与账单小票；完整流水与导出由财务或管理员查看。
- 教练与只读账号可以导出会员名单与预约名单，但不能导出财务流水。
- 只读账号可以查看收支流水与报表，但不能修改任何数据。

## 本次更新（2026-11-18）：教练账号关联与员工自助

> 以下“一 至 十”章节记录的是 2026-11-09 至 2026-11-11 阶段的内容。

### 教练与员工账号打通

- 教练档案新增“关联员工账号”，可把一位教练与角色为“教练”的员工账号绑定，教练就能用自己的账号登录系统。
- 一个员工账号只能关联一位教练，避免两个教练共用一个账号导致考勤与业绩算不清。
- 编辑教练其他资料时，不会重复校验已经建立的关联关系。
- 教练被移入回收站时，关联账号会自动停用；恢复教练或彻底删除后，账号状态随之还原，不会出现“账号莫名失效”。

### 教练照片与课程图片

- 教练编辑页面改为直接上传照片，去掉了多余的“图片网址”输入框，不会再出现两处填写互相冲突。
- 新增“移除照片 / 移除图片”操作，可以一键清空并删除服务器上的旧文件。

### 员工自助管理

- 后台左下角头像点开即为“我的账号”，任何角色的员工都可以修改自己的姓名和绑定手机号，不用再找管理员代劳。
- 同一页面可自助修改登录密码：需校验原密码，且新密码不能与原密码相同。
- 登录名、角色和账号启停仍由管理员在“员工账号”中统一管理，避免越权。
- 停用员工账号前增加二次确认，避免误点导致同事当天无法登录。

### 权限与数据校验

- 购卡、会员卡升额、电子码核销与私教消课营收入账，管理员、财务和前台都可以操作，前台与财务不再互相锁死。
- 教练与只读账号仍可查看业务，但相关编辑按钮会置灰并说明原因。
- 价格、次数、有效天数等数字字段现在会做范围校验，填错时直接给出明确提示，而不是中断整次操作。
- 会员档案的“会籍归属”和会员记录的“所属教练”会校验编号是否存在，避免填错导致保存失败。

### 本次修复

- 修复后台取消预约时课程剩余席位被重复扣减的问题（此前可能显示还有余位，实际已约满）。
- 修复批量导入会员时，同一份文件内出现重复手机号导致整批导入失败的问题。
- 修复会员卡被并发修改时互相覆盖的问题，改为版本校验，冲突时提示刷新后重试。
- 后台修改会员卡时会带上版本号，若这张卡在你编辑期间被签到或其他人改动，会提示先刷新而不会静默覆盖。
- 修复使用系统对接凭证时无法修改会员记录的问题。

## 一、会员预约与课表

- 会员可通过手机号验证码登录，新会员验证后自动建立档案。
- 课程可按团课、私教、评估、工作坊、培训分类筛选。
- 新增**日、周、月三种课表视图**，可切换日期、周或月份，也可快速回到今天。
- 手机端支持左右滑动课表翻页。
- 课程剩余席位按状态显示不同颜色：
  - **绿色：** 余位充足，可以预约。
  - **琥珀色：** 席位紧张，建议尽快预约。
  - **红色：** 已经约满。
  - **灰色：** 课程已开始或已结束。
- 点击课程可查看时间、时长、教练、教室和课程说明。
- 支持会员自主预约、取消预约，以及将课程加入手机日历。
- 预约成功后立即保留席位，**签到时才扣除课程次数或体验券**。
- 重复预约、课程约满、临近开课、没有可用权益等情况会给出明确提示。
- 长页面滚动时，会员端导航会贴顶显示，方便随时切换。
- 预约和取消后的结果提示更加明显，不再受页面滚动位置影响。
- 首页和课表翻页增加过渡动效，浏览体验更加流畅。

## 二、双向二维码签到

新增两种到店签到方式，减少前台逐一核对姓名和会员排队等待：

### 会员出示二维码

1. 会员进入“我的 → 到店签到”，选择“出示我的码”。
2. 前台在预约页面点击“扫码签到”，扫描会员二维码。
3. 系统自动匹配可签到课程并完成签到、消课。
4. 如果同一时段有多节预约，前台可先选择课程，确认前不会扣课。

### 会员扫描课程二维码

1. 前台打开课程“预约名单 → 课程签到码”。
2. 将会员课程码展示在手机或前台屏幕上。
3. 会员进入“我的 → 到店签到”，选择“扫课程码”。
4. 系统只签到该会员本人已经预约的对应课程。

### 使用规则

- 支持团课、私教、评估和工作坊。
- 开课前 30 分钟至课程结束可签到。
- 动态二维码会自动刷新，降低二维码被转发或复用的风险。
- 重复扫码只提示已签到，**不会重复扣课**。
- 误签到可撤销，原会员卡次数或体验券会同步返还。
- 摄像头不可用时，可粘贴完整签到码，或由前台在预约名单中手动签到。

## 三、购卡申请与取消

- 点击“申请购卡”后，会先出现确认框，核对产品后再正式提交。
- 未登录会员完成登录后，仍需确认购卡申请，不会直接生成订单。
- 申请成功后自动打开“我的 → 购卡记录”，可查看订单状态和电子码。
- 待核销订单不会提前开卡，也不会计入已收款。
- 未核销前，会员可以点击“取消申请”，二次确认后取消订单。
- 取消后电子码立即失效，不能恢复或继续使用。
- 已核销或已取消的申请不再显示取消按钮。
- 会员到店付款后，工作人员核销电子码，系统同步完成开卡和入账。
- 后台财务会清楚区分待核销、已入账、已取消和已退款订单。
- 高价或不适合线上申请的产品，可设置为仅到店办理。

## 四、排课与教室管理

- 支持新建、编辑、调课、调整容量、取消课程和复制上周课表。
- 复制上周课表时，系统会检查重复课程、教练冲突和教室冲突，并说明无法复制的原因。
- 私教预约可在一个操作中完成课程安排和会员预约。
- 新建或编辑排课时，冲突教室会立即变为不可选，并显示该时段已有课程或占用信息，不必等到保存后才发现冲突。
- 调整课程时间、教练或教室时，会重新检查冲突。
- 课程容量不能低于已经预约的人数。
- 取消整节课程时，会同步处理相关预约、席位和已扣权益，并保留必要的历史记录。
- 教室总览支持按楼层查看、卡片或列表展示，以及调整教室排列顺序。
- 可登记内部活动、公司活动、企业课等教室占用，并支持修改和取消。
- 教练管理支持独立维护和上传照片。

## 五、会员档案与会员卡

- 会员档案集中展示个人资料、会员卡、预约历史、训练记录、评估记录和合同附件。
- 支持按姓名、英文名或手机号搜索，减少重复建档。
- 卡课产品支持次卡、周期卡、私教卡和组合套餐。
- 组合套餐可按课程类型分别管理权益，签到和撤销都会对应正确的权益项目。
- 支持会员卡延期、批量延期、冻结、恢复和剩余次数校正。
- 支持升卡、转卡和家庭共享，共享会员可按规则使用同一张卡。
- 可发放免费体验券，并用于真实预约和签到消课。
- 支持会员到期提醒、日常跟进提醒和生日前 7 天提醒。
- 合同、评估资料和其他附件支持上传、下载、修改名称或分类、删除及恢复。
- 重要卡权益调整需要填写原因，便于后续核对。

## 六、财务与经营报表

- 到店售卡时，会员卡和购买流水同时生成，避免开卡与入账不一致。
- 支持电子码核销、手工入账、退款和流水导出。
- 手工入账可用于记录系统外完成、但需要统一入账的收入。
- 退款会保留原始记录；全额退款可关联销卡，已产生的上课历史不会被删除。
- 财务页面分别展示现金实收、购买及升卡入账、退款支出和待核销订单。
- 经营报表提供预约人次、实际上课、课程取消、教练课时、教室使用率等数据。
- 现金实收和确认营收分开列示，便于理解收款与实际课程履约之间的差异。
- 年卡、私教和团课按各自业务规则统计营收，报表更贴近实际经营情况。
- 可导出会员、预约和财务数据，用于对账和内部分析。

## 七、后台与手机端体验

- 管理后台补齐中英文双语，可切换界面语言。
- 手机端客户、会员等数据优先采用卡片展示，减少表格拥挤和横向拖动。

## 八、品牌、通知与权限

- 系统品牌统一为“音昱 Wellness”。
- 管理员可上传和替换系统 Logo 及网站图标，也可恢复默认图片。
- 短信通知支持预约成功、预约取消和课前提醒，可按需要分别开启。
- 支持短信余额查询、测试短信和发送记录查询。
- 真实短信启用前可先测试，确认签名、模板、手机号和余额无误后再正式使用。
- 员工账号支持管理员、前台、财务、教练和只读角色。
- 可新增员工、调整角色、重置密码和停用账号。
- 系统对接访问凭证可在后台统一管理，包括使用范围、有效期、启停和使用记录。
- 关键业务操作保留记录，方便追溯预约、签到、购卡、核销、退款和设置变更。

## 九、数据维护与误删恢复

- 支持下载会员导入模板并批量导入会员。
- 重复手机号可选择跳过或更新已有资料。
- 支持会员、预约和财务流水导出。
- 支持立即备份、自动备份、下载备份和按备份恢复数据。
- 恢复数据前会自动保留当前数据副本。
- 可编辑资料、合同和附件均补齐新增、查看、修改和删除能力。
- 删除的数据会进入回收站，管理员可查找并恢复。
- 回收站数据保留 **180 天**，只有管理员且到期后才能彻底删除。
- 合同和附件在回收站期间保留，彻底删除时才清理文件。
- 对仍有有效预约、未来排课或上课历史的数据，系统会阻止直接删除，避免影响正常经营。

> **备份提醒：** 数据库备份不包含合同、照片、Logo 等独立上传文件。完整备份时，还需要同步备份上传文件目录。
